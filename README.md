# Surfside Google Tag Manager Template

This repository contains the official Google Tag Manager (GTM) Community Template for integrating **Surfside** analytics and onsite ad services onto your website.

## Overview

The Surfside GTM template simplifies the process of installing the Surfside pixel and tags for retail menus. It handles tag initialization automatically based on your configured account settings and optional menu integrations.

## Features & Parameters

* **Account ID:** Your 5-character Surfside Account ID.
* **Site ID:** Your 5-character Surfside Site ID.
* **Enable Onsite Ads (SCM):** Toggle to enable ad rendering logic.
* **Supported Menu Types:**
  * **Custom**
  * **Dutchie 2.0** (Supports Banners and Single Page Applications)
  * **IHJ Reverse Proxy**
  * **City Hive**

## Installation & Setup

1. Search for **Surfside Integration** in the Google Tag Manager Community Template Gallery.
2. Add the template to your workspace.
3. Create a new Tag using the **Surfside Integration** type.
4. Enter your **Account ID** and **Site ID**.
5. Enable **onsite Ads** if applicable and select your menu platform.
6. Set your trigger (typically **All Pages** or **Initialization - All Pages**) and publish your container.
